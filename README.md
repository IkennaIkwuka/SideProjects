# SideProjects

Small side projects, done outside of coursework, to practice and showcase progress in different languages.

## Java

- **bmicalculatorapp** — BMI calculator: takes height/weight, calculates and categorizes the result.
- **mortgagecalculatorapp** — Mortgage repayment calculator.
- **rockpaperscissorsgame** — Rock Paper Scissors with a GUI.
- **studentgradingsystemapp** — Takes student scores, calculates averages, assigns grades.

## Python

- **calculatorapp** — CLI calculator, logic and CLI split into separate modules, with tests.
- **numberguessinggame** — CLI number guessing game (guess a number 1-100 within a limited number of attempts). Run: `python3 scripts/game.py`
- **todolistapp** — CLI to-do list app (add/remove/mark tasks done), backed by SQLite. Run: `python3 scripts/run_cli.py`

Each project folder has its own README with more specific setup/run instructions where relevant.
