# Rock Paper Scissors

Rock Paper Scissors with a Java Swing GUI. Click a choice to play a round against the computer; tracks current score and high score, with a reset button.

## Run

```bash
javac -d bin src/main/gui/Main.java
java -cp bin main.gui.Main
```

## Structure

```
src/main/gui/Main.java   # entry point, GUI setup, and game logic
```
