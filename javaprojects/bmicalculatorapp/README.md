# BMI Calculator

Command-line Body Mass Index calculator. Supports both metric (kg/m) and imperial (lbs/in) units, and categorizes the result as underweight, normal, overweight, or obese per WHO BMI ranges.

## Run

```bash
javac -d bin src/main/App.java
java -cp bin main.App
```

## Structure

```
src/main/App.java   # entry point and all logic
```
