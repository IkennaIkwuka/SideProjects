# Student Grading System

Command-line app that takes a student's scores across five fixed subjects (English, Maths, Computer Science, Physics, Chemistry), computes the average, and prints a remark based on the result.

## Run

```bash
javac -d bin src/main/Main.java
java -cp bin main.Main
```

## Structure

```
src/main/Main.java   # entry point and all logic
```
